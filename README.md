# COVID-19 Data Analysis

## About the Project

This project focuses on analyzing COVID-19 data to understand the spread of the virus and changes in cases over time.

The data was cleaned, processed and analyzed to identify important trends and patterns.

## Tools Used

- Python
- Pandas
- NumPy
- Excel
- Power BI

## Analysis Performed

- Total confirmed cases analysis
- Deaths and recoveries analysis
- Country-wise comparison
- Time-based analysis of COVID-19 cases
- Analysis of active cases
- Identifying trends and patterns
- Data cleaning and preprocessing

## Key Insights

The analysis provides an overview of COVID-19 cases, deaths and recoveries and helps understand how the situation changed over different periods and locations.

## Project Outcome

This project helped me improve my skills in data cleaning, analysis and visualization using Python, Pandas and Power BI.
